# Resources

Use this folder for non-secret source material, assets, references, and exports
that support the project but are not current-state owner docs.

Examples:

| Path Example | Purpose |
| --- | --- |
| `resources/research/[source-name].md` | Source-backed research note. |
| `resources/assets/` | Images, logos, templates, and design inputs. |
| `resources/imports/` | Human-provided files awaiting processing. |
| `resources/exports/` | Generated artifacts intended for review. |
